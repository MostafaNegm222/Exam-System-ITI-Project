# Exam System (ITI Project)

A client-side exam system built with vanilla HTML, CSS and JavaScript. Training project built during ITI.

## What It Does

- Multi-page flow starting from sign up / sign in
- Exam pages driven by a questions module (`questions/`)
- Audio cues and image assets included

## Tech Stack

- HTML5, CSS3, vanilla JavaScript (no frameworks, no build step)

## Project Structure

```
├── index.html   # Sign-up page (entry point)
├── pages/       # Exam and other pages
├── questions/   # Question data/logic
├── js/          # Shared scripts
├── styles/      # Stylesheets
├── audios/      # Sound effects
└── images/      # Image assets
```

## Getting Started

Open `index.html` in a browser, or serve the folder with any static server.
